# Match card and poster logos

Place transparent PNG, WebP, or SVG files in this folder.

- The same files are used on match cards and 9:16 posters.

- Files are rendered from left to right in alphabetical filename order.
- Up to four logos are used.
- Replace the files to change the logos; no code changes are required.
- Keep transparent padding tight around each logo.
- Recommended source size: at least 400 px wide.

Examples: 01-ptf.png, 02-sponsor.png, 03-partner.svg.

If the folder is empty, the lower part of the card remains blank.
