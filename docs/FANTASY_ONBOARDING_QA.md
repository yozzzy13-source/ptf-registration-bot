# Fantasy onboarding — проверка 16.09.2026

## Что изменено
- Главный Fantasy-маршрут: вход → игроки → капитан / вице-капитан → название → проверка → подтверждение → команда.
- Первая команда — основное действие. Вторая создаётся отдельно до дедлайна; обе доступны с главной.
- Черновики сохраняются автоматически в существующие Fantasy Teams / Fantasy Test Teams. Правки подтверждённого состава вступают в силу только после повторного подтверждения.
- На подборе: восемь слотов, текущая группа, использованный/оставшийся бюджет, Race-подобные строки с местом, аватаром, Teams, Fantasy Points, ценой и выбором.
- Сохранены отдельные рейтинги, раскрываемые правила, две темы и RU/EN.
- Изменения League ограничены функцией renderFantasy; другие страницы, стили и существующие таблицы League не изменены.

## Точечные серверные исправления
- Все Fantasy API и Fantasy-данные в League bootstrap проходят Players_Master + TEST-проверку.
- Администратор также должен быть в Players_Master и в TEST-группе при режиме TEST. OFF закрывает доступ всем.
- Слоты: 2 C, 2 W, Prime, A, B, flex Prime/A/B. Сохранено требование разных C/W-групп при наличии двух групп.
- Подтверждённую команду можно менять до дедлайна без расходования замен; статус и первоначальный locked_at сохраняются.
- После дедлайна при разрешающем Settings-переключателе доступны только замены; лимит читается из Settings. Бесплатное снятие до первого матча сохраняет лимит.
- Bootstrap возвращает очки каждой своей команды и доступность бесплатных замен.
- Пустые числовые Settings используют существующие значения по умолчанию; изменение дедлайна не использует устаревший каталог.
- Схемы рабочих листов, подсчёт матчевых очков, формула цены и независимость TEST/LIVE сохранены.

## Браузерный прогон и визуальная проверка
Локальный Chrome с мобильной эмуляцией: 390×844 и 320×740, светлая/тёмная темы. API подменён тестовыми данными; реальные команды не создавались.
Проверены:
1. Новый игрок: одна основная кнопка, без предложения второй команды.
2. Неподходящий слот: конкретная ошибка при нажатии.
3. Черновик: выбор, автосохранение, перезагрузка, продолжение.
4. Полный проход: 8 игроков → капитаны → название → серверная проверка → подтверждение → успех → моя команда.
5. Вторая команда: сохранение отдельно, первая не меняется.
6. Подтверждённая команда: редактирование и отмена без изменения сохранённого состава.
7. Дедлайн: нет кнопки обычного редактирования, работает разрешённая замена.
8. Просроченный черновик: явно указано, что он не участвует в рейтинге.
9. RU/EN и узкая ширина: отсутствует горизонтальная прокрутка всей страницы.
10. Отказ в доступе: не отображаются игроки и кнопки Fantasy.

Ошибок JavaScript в браузере нет. Скриншоты сохранены в outputs/fantasy-*.png; визуально просмотрены подбор игроков и review, включая ширину 320 px.
Встроенный Browser и стандартное чтение изображений были недоступны из-за сбоя Windows sandbox, поэтому использованы локальный Chrome и альтернативное чтение PNG.
